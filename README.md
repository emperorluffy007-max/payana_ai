# Payana.ai 🚌✨

A modern, intelligent central navigation hub designed for Bengaluru transit. Payana.ai helps you plan journeys, track live buses, avoid peak congestion, and monitor your environmental impact while reclaiming your commute time.

## 🌟 Features

- **🗺️ Live Map & Transit Tracking:** Real-time tracking of Bengaluru buses. Anticipate your ride and never miss a bus again.
- **🛣️ Quick Routes:** Plan your journeys seamlessly and access your most frequent (starred) routes in a single tap.
- **📊 Peak Insights:** View current traffic trends and congestion levels to optimally plan your commutes and avoid the rush.
- **🌱 Impact & Commute ROI Tracker:** Monitor your carbon footprint reduction and see the "Time Reclaimed" compared to baseline transit solutions like Google Maps.
- **🏆 Leaderboard:** Engage with a community of smart commuters and compete to be the most eco-friendly traveler.
- **🕒 Commute History:** Keep track of your past trips, routes taken, and overall transit performance.
- **🌓 Premium UI & Dark Mode:** A beautiful, responsive glassmorphism interface powered by Framer Motion that adapts to your preferred light or dark theme.

## 💻 Tech Stack

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing:** [TanStack Router](https://tanstack.com/router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/)
- **Maps:** [React Leaflet](https://react-leaflet.js.org/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/payana.ai.git
   cd payana.ai/payana_ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:8080` (or the port specified in your terminal).

## 🛠️ Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build the application for production
